# Impeccable Runtime Pack

Use this as a strict visual critique lens before producing final HTML.

## Non-Negotiables

- Avoid generic AI layout patterns: centered hero, equal card wall, bland icon grid, floating section cards, decorative blobs, and one-note palettes.
- Make hierarchy visible from the first viewport: one dominant idea, one primary CTA, one clear proof or local signal.
- Treat each section as a composed page band, not a stack of cards. Alternate density, scale, background, and media rhythm.
- Use imagery as narrative: crop intentionally, layer copy around it, and never claim editorial media is the real venue unless facts prove it.
- Footer is a brand closing section with contact and local trust, not a leftover bar.

## Quality Pass

- Check contrast, line length, mobile wrapping, CTA visibility, footer quality, and whether every section earns its space.
- If the page feels like a template, change composition before adding decoration.
- Prefer fewer stronger sections over many weak ones.
